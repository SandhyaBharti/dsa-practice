Happy Number => A happy no. means: 
 -> keep doing this: Take each digit, square it, add them, if finally get 1: then it is happy no. otherwise not happy no. 
 Ex: 19: digits are 1 and 9
    Square them-> 1^2 = 1, 9^2 = 81
    Add them -> 1 + 81 = 82
    New no. = 82
    Repeat the same process from beginning

    Code Ex: 
    n = 19
    last digit: n % 19 -> means: 19 % 10 = 9:- last digit is 9
    Remove last digit: n / 10 -> means: 19/ 10 = 1, no. becomes 1

    #pattern is:
        step 1: get digit -> digit = n % 10;
        step 2: use digit
        step 3: remove digit -> n = n / 10;

        this is why we use while loop bcz, we want to repeat until no. becomes 0 

Simple Code: 
int n = 19;
int sum = 0;

while(n != 0) {
    int digit = n % 10;
    sum = sum + (digit * digit);
     n = n / 10;
}
